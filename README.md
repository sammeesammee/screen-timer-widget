## TECHNICAL FEATURES

Despite being constructed entirely through trial, error, and unverified code generation, the application includes the following operational capabilities:

* **Custom Frameless Interface:** Utilises a dark-purple visual theme (`#1e1b2e`) featuring state-switch animations and custom window controls without standard OS window decorations.
* **System Tray Integration:** Runs in the background within the Windows notification area, featuring context menu actions and hidden-to-tray window management.
* **Timeout Configuration:** Facilitates switching between active monitor timeout intervals and a disabled state (`OFF`), supported by customizable interval drop-down selections.
* **Immediate Display Power Off:** Includes an asynchronous display termination routine ("Spegni ora") that immediately commands the monitor to enter a sleep state without blocking thread execution.
* **Single-Instance Enforcement:** Implements a Windows Mutex check upon initialization to prevent duplicate background processes from running simultaneously.
* **Transient Notification System:** Features self-fading status alerts for user actions.
