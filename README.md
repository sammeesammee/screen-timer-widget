# Display Timer Utility

A minimalist, lightweight system tray utility for Windows designed to manage screen timeout intervals, featuring a custom dark-purple interface.

## Core Features

* **Custom Interface:** A borderless, lightweight window featuring a modern dark-purple aesthetic.
* **System Tray Integration:** Operates discreetly in the background within the Windows system tray.
* **Interactive Controls:** Includes visual state indicators for active and inactive states, alongside a dedicated immediate screen-off function.
* **Single-Instance Enforcement:** Built-in mechanism to prevent multiple simultaneous processes.

---

## Usage Instructions

To run the application without setting up a Python development environment:

1. Navigate to the **`dist`** folder.
2. Locate and execute **`Display Timer Utility.exe`**.
3. For persistent background usage, create a shortcut of the executable and place it within the Windows startup directory (`shell:startup`).
